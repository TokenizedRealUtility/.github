## What is TRU?

Tokenized Real Utility (TRU) is a Layer-1 blockchain designed to provide
a transparent and extensible foundation for digital assets and real-world
utility.

TRU includes a native UTXO blockchain, proof-of-work mining, a multi-token
system, programmable contracts, TRUScript inscriptions, decentralized
identity capabilities, token evolution architecture, and infrastructure
for applications built directly around verifiable chain state.

TRU was launched without a premine or presale and distributes native TRU
through proof-of-work mining.

## TRU Ecosystem

### 🧱 TRU Core
The canonical blockchain node, consensus engine, wallet, RPC server,
P2P network and validation implementation.

### ⛏️ Mining
CPU and GPU mining implementations with network miner telemetry and
canonical producer tracking.

### 🪙 Tokens
Native support for multiple asset models including:

- FT — Fungible Tokens
- NFT — Non-Fungible Tokens
- SFT — Semi-Fungible Tokens
- NCFT — Non-Consumable Fungible Tokens

### 📜 TRUScript
On-chain inscription and programmable data infrastructure.

### ⚙️ Smart Contracts
Native programmable contract functionality including multisig,
hash locks, oracle architecture and additional contract primitives.

### 🧬 VAH
TRU's Verifiable Asset History architecture for tracking evolving
digital assets and their canonical history.

### 🌐 Explorer & Web Wallet
A browser-based interface for exploring the blockchain, managing
wallets, creating and transferring assets, viewing miners and interacting
with TRU applications.

## Network Principles

**Proof of Work**  
TRU uses decentralized computational work to secure the network.

**No Premine**  
No TRU supply was allocated before mining began.

**No Presale**  
TRU was not distributed through a token sale.

**Open Participation**  
Independent operators can run nodes and miners.

**Verifiable Chain State**  
Network state is derived from the blockchain rather than a centralized
database.
